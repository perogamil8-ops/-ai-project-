# 📋 وثيقة التسليم وشرح المشروع الشامل (Project Hand-off Documentation)

**المساق:** ذكاء اصطناعي (CAI3101 - AAST)  
**الموضوع:** محرك ألعاب ذكاء اصطناعي خالص بلغة بايثون مع الميزات الإضافية (Pure-Python Game AI Engine + Bonus Features)  
**الألعاب المنفذة:** إكس-أو (Tic-Tac-Toe / XO)، كونكت 4 (Connect 4)، سيجة (Seega)  
**الخوارزميات الأساسية:** ميني ماكس (Minimax)، ألفا-بيتا برونينغ (Alpha-Beta Pruning)، ترتيب الحركات (Move Ordering)، التعميق التكراري (Iterative Deepening)، جدول النقل Zobrist Transposition Table  
**الميزات الإضافية (Bonus Features):** وضع الأصدقاء (Friends Mode)، نظام التلميحات (Hints & Heatmap)، المراجعة الشاملة بعد انتهاء المباراة (Chess-Engine Style Review & Blunder Detection)، شجرة بحث ألفا-بيتا المرئية (Search Tree Visualizer)، شريط التقييم المباشر (Live Eval Bar)، والتراجع والتقدم (Undo/Redo & Save/Load JSON).

---

## 1. الفكرة العامة والهدف من المشروع (Project Overview)

تم بناء هذا المشروع ليكون محرك ألعاب ذكاء اصطناعي متكاملاً ونظيفاً ومكتوباً ببايثون الخالصة (Standard Library فقط دون أي مكتبات ذكاء اصطناعي خارجية).  
يقوم المحرك بتمثيل الحالات بشكل غير قابل للتعديل (Immutable States)، ويقدم خوارزميات بحث عامة تعمل مع أي لعبة (Game-Agnostic)، مع دعم واجهة اختبار ويب خفيفة وسريعة عبر FastAPI و HTML/JS و Canvas دون أي مكتبات رسوم بيانية خارجية.

## 3. تفاصيل الميزات الإضافية المنجزة (Bonus Features Detailed)

### 3.1 إزالة افتراض أن الكمبيوتر هو MAX دائماً (Step 0)
- تم تعديل خوارزميات البحث بحيث تقوم بالتقييم من منظور **اللاعب الذي عليه الدور** (`perspective=None` أو المنظور المحدد).
- إضافة دالة `best_move(game, state, algorithm, depth, perspective=None)` التي تبحث دائماً عن أفضل حركة للمنظور المطلوب.
- إضافة دالة `score_all_moves(game, state, depth)` التي تقيّم كل حركة متاحة عند الجذر باستخدام نافذة بحث كاملة $(\alpha = -\infty, \beta = +\infty)$ لضمان الحصول على تقييم دقيق لكل حركة (وليست مجرد حدود تقريبية).
- إثبات تماثل المنظور باختبارات مؤتمتة: تقييم الوضعية للاعب الأول يساوي دائماً سالب تقييمها للاعب الثاني.

### 3.2 وضع اللعب مع صديق (Friends Mode / Split-Screen)
- متاح لجميع الألعاب الثلاثة مع لوحة تحكم منقسمة (Split-screen).
- تناوب بين "Player 1" و "Player 2" على نفس الشاشة (Hot-seat).
- في لعبة سيجة: يضع اللاعب الأول قطعتين يدوياً، ثم يضع اللاعب الثاني قطعتين يدوياً، بدون أي وضع عشوائي للكمبيوتر.

### 3.3 نظام التلميحات الذكي (AI Hint System)
- زر `💡 Hint` متاح للاعب البشري (ولكلا اللاعبين في وضع الأصدقاء).
- يحدد أفضل حركة ويظهر وميضاً وإطاراً مخصصاً على اللوحة.
- في لعبة Connect 4: يعرض خريطة حرارية رقمية (Score Heatmap) فوق كل عمود لتوضيح تقييم كل عمود.
- في لعبة سيجة: يوضح القطعة والمربع المستهدف، وفي مرحلة الإسقاط ينبه المستخدم بأن التلميحات متاحة فقط في مرحلة الحركة.
- عداد تلميحات متبقية (3 تلميحات لكل مباراة افتراضياً).

### 3.4 مراجعة المباراة وتحليل الأخطاء (Chess-Engine Style Review)
- يتم تسجيل المباراة بالكامل خطوة بخطوة.
- عند انتهاء المباراة، يظهر زر `🔍 Analyze Game` ليقوم المحرك بتحليل كافة النقلات:
  1. حساب تقييم أفضل حركة ممكنة `best_score`.
  2. حساب تقييم الحركة التي لعبها اللاعب فعلياً `played_score`.
  3. تحويل التقييم إلى احتمالية فوز عبر الدالة اللوجستية: $p = 1 / (1 + e^{-\text{score} / k})$.
  4. حساب الفقد في احتمالية الفوز: $\Delta p = \max(0, p_{\text{best}} - p_{\text{played}})$.
  5. تصنيف النقلات وفق معايير واضحة وموثقة:
     - **Best (ممتازة)**: $\Delta p \le 0.005$ أو نفس حركة المحرك.
     - **Good (جيدة)**: $\Delta p \le 0.05$.
     - **Inaccuracy (غير دقيقة)**: $\Delta p \le 0.12$.
     - **Mistake (خطأ)**: $\Delta p \le 0.25$.
     - **Blunder (فادحة)**: $\Delta p > 0.25$.
  6. حساب نسبة دقة كل لاعب (Accuracy %) وإظهار اللحظة الحرجة (Critical Moment - أكبر خطأ غيّر مجرى المباراة).
  7. رسم بياني لتطور التقييم عبر الزمن (Canvas Line Chart) مع إمكانية الضغط على أي نقلة أو استخدام الأسهم في لوحة المفاتيح للتنقل بين النقلات ورؤية الحركة الملعوبة باللون الأحمر ومقارنتها بالحركة الأفضل باللون الأخضر مع نص توضيحي.

### 3.5 ميزات إضافية متقدمة (Feature 4 Enhancements)
1. **شجرة بحث ألفا-بيتا المرئية (Search Tree Visualizer لـ XO)**:
   - توليد شجرة هرمية كاملة توضح قيم $\alpha$ و $\beta$ والقيمة المحسوبة مع شطب فروع الشجرة التي تم تقليمها (Pruned Branches).
2. **التعميق التكراري (Iterative Deepening - مستوى Expert)**:
   - البحث في أعماق متتالية (1 ثم 2 ثم 3...) مع حد زمني بالمللي ثانية لضمان أفضل حركة في الوقت المتاح.
3. **جدول النقل زوبريست (Zobrist Transposition Table لـ Connect 4)**:
   - تمثيل اللوحة ببصمة 64-بت وتخزين العقد المكررة لتسريع البحث وتقليص العقد الإضافية.
4. **شريط التقييم المباشر (Live Eval Bar)**:
   - خيار لتفعيل شريط احتمالية الفوز أثناء اللعب.
5. **التراجع والتقدم وحفظ اللعبة (Undo / Redo & Save / Load JSON)**:
   - التراجع والتقدم بنقرة واحدة وحفظ/استرجاع المباريات كملف JSON.

## 4. نتائج الاختبارات (Test Verification)

تم تشغيل حزمة الاختبارات الشاملة المكونة من **51 اختباراً مؤتمتاً** وتجاوزتها جميعاً بنجاح كامل:
- `test_xo.py` (8 اختبارات): فحص خطوط الفوز، التعادل، وإثبات عدم خسارة المستوى الصعب ضد جميع التفرعات البشرية الممكنة.
- `test_connect4.py` (9 اختبارات): فحص الجاذبية، رفض الأعمدة الممتلئة، خطوط الفوز الأربعة، وحالة التعادل الحقيقية.
- `test_seega.py` (10 اختبارات): فحص قواعد سيجة بمرحلتيها، منع المركز في الإسقاط، الحصر، حصانة المركز، وقاعدة 40 حركة.
- `test_search.py` (4 اختبارات): فحص تطابق Minimax و Alpha-Beta على أكثر من 100 وضعية لكل لعبة.
- `test_step0.py` (6 اختبارات): فحص تماثل المنظور بين P1 و P2 وتطابق `score_all_moves` مع `best_move`.
- `test_features.py` (10 اختبارات): فحص وضع الأصدقاء، التلميحات، كشف الـ Blunder في XO، دقة 100% في اللعب المثالي، وشجرة البحث، وجدول زوبريست.
- `test_api.py` (4 اختبارات): فحص الـ Endpoints والتحقق من صحة المدخلات.
